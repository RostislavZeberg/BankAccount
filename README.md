# Bank Account Management System

Современное веб-приложение для управления банковскими счетами с адаптивным дизайном и интуитивно понятным интерфейсом.
Ссылка для просмотра:
https://frontend-ogyw015eh-zebergs-projects.vercel.app/

## 🚀 Особенности

- **Управление счетами**: Просмотр, создание и сортировка банковских счетов
- **Переводы средств**: Безопасные переводы между счетами
- **История операций**: Детальная история всех транзакций
- **Валютные операции**: Обмен валют в реальном времени
- **Визуализация данных**: Графики и диаграммы для анализа финансов
- **Адаптивный дизайн**: Оптимизирован для всех устройств

## 📱 Адаптивность

Приложение полностью адаптировано для различных разрешений экрана:

- **480px+** - Мобильные устройства
- **768px+** - Планшеты
- **992px+** - Ноутбуки и маленькие мониторы
- **1200px+** - Большие мониторы и десктопы

## 🛠 Технологии

- **Frontend**: Next.js 15, React 19, TypeScript
- **Стили**: Tailwind CSS
- **Графики**: Chart.js, React-Chartjs-2
- **State Management**: Redux Toolkit
- **HTTP Client**: Axios
- **WebSocket**: Real-time обновления курсов валют

## 📦 Установка и запуск

### Предварительные требования

- Node.js 18+ 
- npm или yarn

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd frontend
```

2. Установите зависимости:

```bash
npm install
# или
yarn install
```

3. Запустите приложение в режиме разработки:

```bash
npm run dev
# или
yarn dev
```

4. Откройте http://localhost:3000 в браузере

### Сборка для production
```bash
npm run build
npm start
```

## Основные страницы
### Главная страница (/)
- Авторизация в системе
- Адаптивная форма входа

### Счета (/account)
- Обзор всех счетов пользователя
- Сортировка по номеру, балансу или дате транзакции
- Создание новых счетов
- Карточки счетов с основной информацией

### Детали счета (/account/[id])
- Детальная информация о счете
- График истории баланса
- История транзакций
- Форма перевода средств

### История баланса (/account/[id]/balance-history)
- Подробная история баланса за 12 месяцев
- Графики входящих и исходящих транзакций
- Пагинация истории операций

### Валютные операции (/currency)
- Просмотр валютных счетов
- Обмен валют в реальном времени
- Отслеживание курсов через WebSocket

## 🔄 API Endpoints
Приложение взаимодействует с бэкенд-API через следующие endpoints:

- POST /login - Авторизация
- GET /accounts - Получение списка счетов
- POST /create-account - Создание нового счета
- GET /account/{id} - Получение деталей счета
- POST /transfer-funds - Перевод средств
- GET /all-currencies - Список валют
- GET /currencies - Валютные балансы
- POST /currency-buy - Покупка валюты
- WebSocket /currency-feed - Real-time курсы валют
